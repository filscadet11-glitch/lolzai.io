# Pennywise

A lightweight, single-page expense tracker and pricing experience for GitHub Pages. The dashboard lets visitors record income and expenses, review balances and category totals, and filter transactions by month or all time.

## Run locally

Open `index.html` in a browser. Transactions are stored in that browser's local storage; there is no account, server, or bank connection.

## Plans

- **Free:** $0
- **Monthly:** $5 per month
- **Annual:** $48 per year (equivalent to $4 per month; save 20%)

Paid-plan buttons are informational previews; payment processing is not connected.

## Publish

To publish with GitHub Pages, open the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. The site is served from `index.html`.
