# Money, Made Clear — Day 1 Download Site
The GitHub Pages site provides the 10-minute Day 1 video, a YouTube upload kit, and channel branding assets.

## Download
Open the homepage to preview the new video and download the MP4 to a Mac. The complete ZIP includes the video, 1280 × 720 thumbnail, SRT captions, title and description, and editable narration script. The homepage also links to the channel banner.

The large MP4 and ZIP are GitHub Release assets so they can be downloaded without storing large binaries in the Pages source branch.

## Publishing
To make the website public, open the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub will show the public Pages URL in the same settings page. The current download links use public GitHub Release assets.

Upload updated large video deliverables as assets to a GitHub Release and keep the release asset filenames in sync with the download links in `index.html`.
